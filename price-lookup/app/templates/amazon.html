📥 Import Amazon order history
  1. Go to amazon.com.au → Account → Request Your Data (Privacy Central)
  2. Choose "Your Orders" from the dropdown → Submit Request
  3. Confirm via the email Amazon sends, then wait (usually a few hours)
  4. Download & unzip the archive; find Retail.OrderHistory.1.csv
  5. Upload that CSV below

Amazon retired the old one-click "Order History Reports" page, so this data request is now the official route. Re-uploading the same CSV is safe — already-imported order lines are silently skipped.
